# Post-crash check: costs, revenue, profit (model v2, 31 Oct 2026)

A model on our own estimates, not a forecast. Nothing here is quoted yet. Public page shows only this v2 base case; the downside sensitivity stays in this file for the team and for investor questions.

## v2 structure: built so the base case earns money
1. **Yearly contract floor.** Sign an insurer only if the contract has an on call fee (assumed EUR 500 a month = EUR 6,000 a year) plus per check fees, so fixed costs are covered before volume.
2. **Technicians paid per case.** HV qualified contractors or a partner garage, paid per check. No staff, no site.
3. **Kit after signature.** Buy the EUR 2-4k kit only after a signed contract or letter of intent.
4. **Stop rule.** Any false all clear stops the pilot; pilot cash cap EUR 6-8k.

## Inputs (all estimates)
| Input | v2 value | v1 value | Note |
|---|---|---|---|
| Price per check | EUR 200 | 200 | test 150-250 |
| Cost per check | EUR 110 | 160 | per case contractor at a partner garage; TARGET, unverified (v1 mobile estimate was 120-200) |
| Fixed costs per year | EUR 8k Latvia, 12k Baltics | 12k | ASSUMPTION: insurance, training, legal, accounting, kit depreciation. No quotes. |
| On call fee per insurer | EUR 6k a year | none | ASSUMPTION, untested |
| Checks per year | 57 Latvia, 250 Baltics | same | our estimate |

## Base case results (per year)
| Scenario | Revenue | Costs | Profit |
|---|---|---|---|
| Latvia, one insurer: 57 x 200 + 6k fee | 17,400 | 6,270 variable + 8,000 fixed = 14,270 | **+3,130** |
| Baltics, per check fees only: 250 x 200 | 50,000 | 27,500 + 12,000 = 39,500 | **+10,500** |
| Baltics, three insurers: 250 x 200 + 18k fees | 68,000 | 39,500 | **+28,500** |
Break even: (fixed - on call fees) / (price - cost) = (8,000 - 6,000) / 90 = about 22 checks with one on call fee; 12,000 / 90 = about 133 checks on per check fees alone.

## Downside sensitivity (not on the page)
| If | Result |
|---|---|
| Cost per check stays EUR 160 (v1), Baltics, no on call fee | 50,000 - 40,000 - 12,000 = -2,000 |
| Same, Latvia only, no on call fee | 11,400 - 9,120 - 12,000 = -9,720 |
| Insurers refuse an on call fee | Latvia one insurer: 11,400 - 6,270 - 8,000 = -2,870; Baltics still +10,500 only if cost per check is 110 |
| Nobody signs | we stop after the pilot; loss limited to the cash cap, EUR 6-8k |
Honest wording for investors: "Profit holds if cost per check is about EUR 110 and insurers accept the contract floor. If no insurer signs we have spent only the pilot cap." Never say "cannot lose".

## What would make it more profitable (levers)
- Price EUR 250 instead of 200: Baltics per check only becomes 250 x 140 - 12,000 = +23,000.
- More cases: hybrids and plug-ins count; leasing and tow firm customers; Nordics (larger but with incumbents).
- Pack take back when the verdict is "replace" (earlier model: about EUR 268 contribution per pack on a prepaid, quoted basis; damaged packs cost more to move, so not counted).
- Shared savings alone does not help: 10-15% of EUR 435 = EUR 44-65 per check.
