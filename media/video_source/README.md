# Explainer video source

`../climathon_concept_video.mp4` (about 2 min, narrated, with subtitles) is generated by these files.
To change the story: edit `narration.json` (one string per scene) and the scene functions in `render.py`, then:

1. `powershell -File tts.ps1` creates `narr_01.wav` ... with Windows text-to-speech (voice: Microsoft Zira)
2. `python render.py` (needs Python with Pillow and numpy, and `ffmpeg` on PATH) writes `concept.mp4`
   (`python render.py preview` also saves one still frame per scene)

The 30 % / 70 % split shown in the video is our starting hypothesis, not a validated number.
